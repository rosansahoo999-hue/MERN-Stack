## Let & Const Keywords (ES6):-
# var:-
- Used to define variables which can be ressigned.
- Variable defined with var are accessible globally.

# let:- 
- Used to define variables which can be reassigned(same as var).
- Variable defined with let are accessible within the block it is declared.\

# const:-
- Used to define variables which cannot be reassigned.
- Variable defined with const are accessible globally.

## Arrow function in ES6:-
- An Arrow Function is a shorter way to write functions in ES6 (ECMAScript 2015). 
- It uses the => symbol and makes code cleaner and easier to read.

## Arrow Function("this") Keyword:-
- this refers to the current execution context (object) in JavaScript.
- In regular function, this is dynamic it depends on how the function is called arrow function.
Key Characteristics:-
> No own this:- Arrow function cannot define their one this.
> Lexical Scoping:- this is inherited from the outer function or global scope.
> Cannot be changed:- Methods like call(), apply(), and bind() do not affect this in arrow function.
> Not suitable as method:- Since this does not refer to the object, arrow functions should not be used as object methods.
